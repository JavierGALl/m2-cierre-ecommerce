- Instalación de git
- Creación de cuenta en Github
------------------------------------------------------------------------------------------
-- Configurar nuestro entorno para conectarse con github
git config --list
git config --global user.name "Nombre usuario"

git config --global user.email email@gmail.com
------------------------------------------------------------------------------------------

(página 15)
git init
git add . / --all / archivo.html
git commit -m "mensaje"
git push origin main (main hace referencia a la rama)
------------------------------------------------------------------------------------------
(página 20)
git status
------------------------------------------------------------------------------------------
(página 21) -> cambio de nombre archivos
git mv antiguo.html nuevo.html

------------------------------------------------------------------------------------------
(página 22)
crear archivo llamado:
.gitignore
------------------------------------------------------------------------------------------
git checkout -b feature_x : para crear nueva rama y cambiarse

git checkout main / master : para cambiarse a otra rama

git branch -d feature_x: para eliminar una rama

git push origin <rama>: para subir esa rama github
------------------------------------------------------------------------------------------
(página 25)

git merge <rama> : para fusionar ramas
* también se puede usar git pull
------------------------------------------------------------------------------------------
(página 26)

git log : permite ver el historial de cambios
git log --oneline : permite ver el historial de cambios resumido
------------------------------------------------------------------------------------------
git checkout (hash de la versión) : para ver el proyecto en un punto determinado

------------------------------------------------------------------------------------------
(página 28)
git tag v1.0 : crear una etiqueta ligera (creación de versión estable)

git tag -a v1.0 -m "Primera versión estable" : forma más completa

git push origin v1.0 : para enviar la versión a github

------------------------------------------------------------------------------------------
(página 36)
git fetch origin: Descargar cambios en repositorio remoto, pero sin fusionar con rama local

git pull origin main : fusiona automáticamente los cambios con la rama actual.

------------------------------------------------------------------------------------------
(página 41)
Creación de rama gh-pages:

git checkout -b gh-pages
git push origin gh-pages
