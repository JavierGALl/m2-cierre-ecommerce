# 🛒 Proyecto Final – Módulo 2  
## Sitio E-Commerce de Suplementos Fitness

Este proyecto corresponde al trabajo de finalización del **Módulo N°2** del curso.  
Consiste en el desarrollo del **front-end completo** para un sitio web de e-commerce orientado a la venta de **suplementos e implementos fitness**.

---

## 🚀 Descripción del Proyecto

El objetivo del proyecto es construir una interfaz moderna, funcional y responsive utilizando **HTML, CSS y Bootstrap 5**.  
Actualmente el sitio es estático, pero está diseñado pensando en una futura integración con JavaScript para funcionalidades dinámicas como carrito, stock y lógica de productos.

---

## 🧩 Características Principales

### ✔️ Barra de navegación
Incluye enlaces a:
- Inicio  
- Sección de Productos  
- Página del Carrito  

La barra es completamente responsive gracias a Bootstrap.

---

### ✔️ Hero Section
- Imagen destacada a pantalla completa  
- Mensaje principal del sitio  
- Botón que dirige a la sección de productos  

---

### ✔️ Galería de Productos
- Diseño con tarjetas de Bootstrap  
- Cada tarjeta incluye:
  - Imagen
  - Título
  - Breve descripción
  - Precio
  - Botón **“Ver detalles”** (por ahora estático)

---

### ✔️ Página de Detalles del Producto
- Imagen del producto  
- Información detallada  
- Precio  
- Botón de agregado al carrito (demostrativo)  
- Acordeón con:
  - Características técnicas  
  - Recomendaciones de uso  
  - Formas de entrega  

---

### ✔️ Página del Carrito (estática)
Diseñada como base para futura integración con JavaScript.

---

## 🛠️ Tecnologías Utilizadas

| Tecnología | Uso |
|-----------|-----|
| **HTML5** | Estructura del sitio |
| **CSS3**  | Estilos personalizados |
| **Bootstrap 5.3** | Diseño responsive y componentes |
| **JavaScript básico** | Lógica inicial de botones y alertas |
